# BidLab Test Coverage

This document outlines the test suites used to ensure OpenRTB and IAB GPP (Global Privacy Platform) compliance within the BidLab environment.

## Execution
Tests are run via the root `npm test` command, which executes the following suites:
```bash
npm test
```

## 1. OpenRTB Validation (`tests/openrtb-validation.js`)
Ensures that the bid requests and responses generated by the BidLab engine adhere to the OpenRTB 2.6 specification.

### Coverage:
- **BidRequest Structure**:
  - Required fields: `id`, `imp`, `site`/`app`, `device`, `user`.
  - `imp` objects: Must have an `id` and at least one media type (`banner`, `video`, or `native`).
  - `banner` objects: Must specify dimensions or formats.
- **Privacy Regs**:
  - `regs.gpc`: Must be '0' or '1' (string-formatted per common ad tech implementation).
  - `regs.gpp`: Validates presence of GPP string.
- **BidResponse Structure**:
  - Required fields: `id`, `seatbid`.
  - `seatbid` & `bid`: Validates nested bid objects for `id`, `impid`, `price`, and `adm` (creative).

## 2. GPP Compliance (`tests/gpp-validation.js`)
Validates that GPP strings generated for different jurisdictions are mathematically valid and correctly formatted according to the IAB GPP specification (v1.1).

### Positive Test Cases (Success Scenarios):
- **EU (TCF v2.2)**: Standard GPP string validation.
- **US National**: Standard and GPC-active strings (including Section ID 1 declaration).
- **California (CCPA/CPRA)**: Standard and GPC-active strings.
- **Virginia (VCDPA)**: Standard and GPC-active strings.

### Negative Test Cases (Failure Scenarios):
- **Invalid Characters**: Detects characters outside the Base64URL set.
- **Malformed Header**: Detects strings where the header segment cannot be decoded.
- **Section Mismatch**: Detects strings where the declared Section IDs in the header do not match the expected jurisdiction (e.g., US National string with only Section 7 declared but missing Section 1).

- **GPP Compliance**: ✅ 100% Passing (All 10 jurisdiction variants + 3 negative cases)
